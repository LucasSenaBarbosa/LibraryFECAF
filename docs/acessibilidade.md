# Recursos de acessibilidade

O LibraryFECAF não classifica um livro como "acessível" ou "não acessível".
Em vez disso, cada obra informa quais recursos de acessibilidade específicos
possui, permitindo que cada pessoa identifique se o livro atende às suas
necessidades de leitura.

## Recursos considerados na primeira versão

### Audiolivro
Indica que a obra possui uma versão narrada em áudio, útil para pessoas com
deficiência visual ou com dificuldades de leitura de texto impresso.

### Braille
Indica que a obra está disponível em uma edição transcrita para o sistema
Braille.

### E-book acessível
Indica que a versão digital do livro segue boas práticas de acessibilidade
(por exemplo, texto estruturado e navegável), permitindo uso com tecnologias
assistivas.

### Fonte ampliada
Indica que existe uma edição com fonte de tamanho maior, facilitando a
leitura por pessoas com baixa visão.

### Compatibilidade com leitor de tela
Indica que o formato digital do livro é compatível com leitores de tela,
permitindo que o conteúdo seja lido em voz alta por softwares assistivos.

## Como isso é usado no sistema

Cada livro cadastrado armazena um valor booleano (verdadeiro/falso) para cada
um desses recursos. Ao listar os livros, o sistema exibe quais recursos estão
disponíveis para cada obra, para que o leitor identifique rapidamente se ela
atende ao seu formato de leitura preferido.

## Evolução futura

Novos recursos de acessibilidade poderão ser adicionados conforme o projeto
evoluir (por exemplo: LIBRAS, formatos DAISY, entre outros), assim como
funcionalidades de busca e filtro por recurso específico.
